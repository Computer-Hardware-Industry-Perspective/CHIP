# 📚 CHIP Curriculum Overview

**Computer Hardware & Industry Perspective (CHIP)** 스터디는  
컴퓨터 하드웨어를 직접 체험하고, 산업 흐름까지 통찰하는 것을 목표로 합니다.

---

## 🎯 목표

- 컴퓨터 하드웨어의 내부 구조와 원리 이해
- 주요 부품의 역할/동작 방법 분석
- 반도체 및 컴퓨팅 산업 트렌드 학습
- Hands-on 실습과 토론

---
